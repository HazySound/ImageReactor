## ✨ 주요 기능
- 🖼️ **이미지 기반 자동화**: 준비한 이미지를 기준으로 화면 인식 후 키보드/마우스 입력 실행  
- 🖱️ **GUI 기반 설정**:  
  - 클릭 / 키보드 입력 동작 등록  
  - Client 이미지(앵커) 지정 → 해당 이미지가 사라지면 반복 중지  
  - 이벤트별 알림 설정 (토글 체크박스)  
- 🎯 **목표 달성 모드**  
  - 점수/등수 OCR 인식 → 목표치 도달 여부 자동 판정  
  - 목표 충족 시 루프 종료 or 알림 전송  
  - ⚠️ **필수 설치 프로그램: Tesseract OCR**  
    - 인터넷 환경이 가능하다면 [Tesseract OCR 공식 배포판 (UB Mannheim)](https://github.com/UB-Mannheim/tesseract/wiki)에서 설치  
    - 인터넷이 불가한 경우, 프로그램 릴리즈에 포함된 **"필수 설치 프로그램" 폴더 내 설치 실행파일**로 설치 가능
- 📨 **자동 이메일 알림**  
  - 특정 이벤트 발생 시 자동 발송 (메일 제목/내용 커스터마이즈 가능)  
  - Gmail / Naver 메일의 **앱 비밀번호** 사용  
- ❄️ **Freeze Monitor**  
  - 화면이 장시간 동일할 경우 자동 감지 후 알림 메일 발송

## 📂 설치 및 사용 방법
1. 프로그램 실행 시 자동으로 해상도별 리소스 폴더 생성  
   - 경로: `./resources/[가로]x[세로]/`  
2. 이미지 파일은 **.png 확장자**만 지원  
   - 다른 확장자(jpg, gif 등) 및 한글 파일명은 지원하지 않음  
3. Client 이미지를 지정하지 않으면 **직접 종료 전까지 무한 반복**  
4. 목표 달성 모드를 사용하려면 **Tesseract OCR**을 반드시 설치해야 함
